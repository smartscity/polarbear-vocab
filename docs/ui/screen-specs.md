# Screen Specifications

## Home

Show exactly three product layers: dataset progress and Continue, 30-day activity with three aggregate metrics, and history-derived mistake collections. Do not add streaks, goals, schedules, or mastery indicators.

## Datasets

Dataset List supports selection and creation. Dataset Detail shows origin, item count, start, CSV import, rename, and delete actions. Destructive actions require a confirmation dialog; CSV import requires a deterministic validation preview.

## Study and Answer Result

Study is a single stable question surface with visible numeric keyboard shortcuts and immediate selected-option feedback. Answer Result replaces the question in the same frame, exposes pronunciation controls, and supports Space for the next question. Global navigation is hidden.

## Mistakes

Show history-derived filters, word-level correct/wrong counts, and a direct practice action. Empty collections use the shared EmptyState.

## Settings

Expose language and appearance in shared SettingsSection rows. Language and theme changes apply immediately, including system-preference changes.

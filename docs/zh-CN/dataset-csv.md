# 数据集 CSV 格式

Polarbear Vocab 可以把本地 CSV 文件直接导入当前数据集。应用会先校验整个文件并显示预览；只有全部行都有效时才能确认导入。整次导入在一个数据库事务中完成，失败时不会留下部分数据。

## 列

| 列名 | 必填 | 含义 |
| --- | --- | --- |
| `sense_uid` | 否 | 词义的稳定标识。留空时按 `en:{lemma}:{pos}:1` 生成。 |
| `lemma` | 是 | 测验中显示的英文答案。 |
| `pos` | 否 | 词性，默认为 `unknown`。 |
| `quiz_prompt_zh` | 是 | 含义明确的中文题干。 |
| `gloss_zh` | 否 | 答题后显示的中文释义，默认使用题干。 |
| `ipa_us` | 否 | 美式音标。 |
| `ipa_uk` | 否 | 英式音标。 |
| `example_en` | 否 | 简短的英文例句。 |
| `example_zh` | 否 | 例句的中文翻译。 |

文件不能超过 10 MB，最多包含 50,000 行词汇数据。`lemma` 最多 100 个字符，`quiz_prompt_zh` 最多 300 个字符，同一个文件中不能出现重复的 `sense_uid`。

可以从 [`data/examples/dataset-template.csv`](../../data/examples/dataset-template.csv) 开始编辑。中文题干应当足够具体，保证四个英文选项中只有一个正确答案。

导入时会按稳定标识更新已有词义，并将其加入当前数据集。同一词义可以属于多个数据集，因此修改共享 `sense_uid` 的内容会影响所有包含它的数据集。
